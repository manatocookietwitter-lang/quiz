# 審査担当者向けメモ

## App Store / Google Play共通

QuizMakeの問題作成・学習・端末内バックアップは、アカウント登録やログインなしで利用できます。

初回起動時に「サンプルで試す」を選ぶと、英語のサンプル問題セットが追加されます。次の機能を外部サービスなしで確認できます。

1. ホームで「英語サンプル」を開く
2. 「英語の基本問題」を開く
3. 順番またはランダム出題を開始
4. 回答して採点・解説・復習登録を確認
5. メニューからJSONバックアップとプライバシーポリシーを確認

クラウド同期と共有は任意機能で、利用時のみメールアドレスのMagic Linkでログインします。同期データはログイン中のアカウントと144bitのランダムな秘密IDの両方で保護されます。同期を使わなくても問題作成、演習、復習、バックアップの主要機能を利用できます。

ログインアカウントと関連する共有・同期データは、設定画面の「ログインアカウントを削除」からまとめて削除できます。同期データだけを削除する場合は「端末間の同期」の「クラウドデータを削除」を使用できます。

ChatGPTとの連携はAPI通信ではありません。アプリ内のテンプレートを利用者がクリップボードへコピーし、外部で作成したJSONを利用者が明示的に読み込む方式です。

広告、アクセス解析、トラッキング、アプリ内課金はありません。
